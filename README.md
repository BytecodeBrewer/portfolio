# Lev - Data Projects

Personal portfolio focused on data engineering, analytics, automation, and AI-enabled systems.

The site now presents projects as short product case studies: problem, solution, system flow, roadmap, and repository link.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

Built with Next.js for Vercel. Pushes to `main` should create production deployments once the Vercel project is connected to this repository.
